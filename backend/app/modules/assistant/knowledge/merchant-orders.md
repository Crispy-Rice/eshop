## 订单的单位是「子单」

一个买家一次可能买多家店的东西，那会拆成**每店一个子单**。
你只看到和处理自己店的子单 —— 发货、售后都是按子单走的。

## 订单状态

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| 待付款 | 买家还没付钱 | 什么都不用做，超时会自动关闭 |
| 待发货 | 已付款，等你发货 | **要发的就是这些** |
| 待收货 | 已发货，在途 | 等买家确认收货（超时会自动确认） |
| 已完成 / 已关闭 | 终态 | - |

**「待发货」是你能发货的那种状态**，概览里的那个数字就是它。

## 发货

发货按子单发。发货仓是下单时定好的（见「仓库与库存」），不要指望改区域规则来换仓。
发货时需要填物流公司和运单号。

## 售后 / 退款

流程通常是：买家申请 → **你审核** → （需要寄回时）买家寄回 → **你确认收货** → 质检
→ 退款到账。某些环节有**时限**，超时会自动流转到下一步，所以待处理的要尽快看。

「待我处理」包含三种：**待审核、待收货、质检中**。概览里的"待处理售后数"就是这三种之和。

**退不退运费**，看情况：

| 情况 | 运费 |
|---|---|
| 未发货、整单退 | 退全部运费 |
| 未发货、部分退 | 退该子单对应的运费 |
| 已发货、**部分**退货 | **不退运费**（包裹已经发出，运费已经产生了） |
| 已发货、整单退且是质量问题 | 退运费，退货运费由你承担 |
| 已发货、整单退且非质量问题 | 退**发货运费**，退货运费买家承担 |

**退货入库**：质检合格的商品会回到可售库存；不合格的进残次品池，**不会**回到可售。
所以别以为"退回来就能接着卖"。

## 售后有时限

每个环节都有处理时限，超时系统会自动推进（比如自动同意、自动退款）。
**拖着不处理不会让它消失**，只会让你失去商量的余地。
